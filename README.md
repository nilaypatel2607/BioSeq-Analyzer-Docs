# 🧬 BioSeq Analyzer

**BioSeq Analyzer** is a Python-based bioinformatics web application built using Streamlit. It allows users to analyze DNA sequences and obtain useful sequence information through a simple and interactive interface.

The application performs basic DNA sequence analysis, calculates nucleotide composition, determines GC and AT content, generates reverse complement sequences, and provides visual representations of DNA composition.

## 🚀 Features

- **DNA Sequence Validation:** Checks whether the entered DNA sequence contains valid nucleotide characters.
- **Sequence Information:** Calculates the total sequence length.
- **Nucleotide Composition:** Counts the number of Adenine (A), Thymine (T), Guanine (G), Cytosine (C), and ambiguous (N) nucleotides.
- **GC Content:** Calculates the percentage of Guanine and Cytosine in the sequence.
- **AT Content:** Calculates the percentage of Adenine and Thymine in the sequence.
- **Reverse Complement:** Generates the reverse complement of the input DNA sequence.
- **DNA Visualization:** Displays nucleotide composition through an interactive chart.
- **File Upload:** Supports uploading DNA sequence files.
- **Downloadable Reports:** Allows users to download the analysis report and reverse complement sequence.

## 💻 Installation and Setup

Follow these steps to run BioSeq Analyzer on your local machine.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd BioseqAnalyzer
```

**3. Install the required dependencies**

```bash
pip install -r requirements.txt
```

**4. Run the application**

```bash
streamlit run BioSeq_Analyzer.py
```

The application will open in your default web browser.

*Note: If your Python file has a different name, replace `BioSeq_Analyzer.py` with the actual filename.*
